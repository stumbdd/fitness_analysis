# Анализ режима сна и активности по данным фитнес-браслета

Проект на Python для анализа синтетических данных о сне и физической активности, имитирующих показания фитнес-трекера за 145 дней (январь – май 2026).  
Отвечает на вопрос: **какие выводы можно сделать о режиме сна и активности на основе этих данных?**

## Обзор проекта

Программа генерирует реалистичные данные за ~5 месяцев, имитирующие показатели Fitbit/Garmin, и предоставляет интерфейс командной строки для их анализа.

**Колонки датасета:**

|         Колонка       |  Тип  |           Описание           |
|-----------------------|------ |------------------------------|
| `date`                | date  | Дата измерения               |
| `day_of_week`         | str   | День недели                  |
| `is_weekend`          | int   | Выходной (1) или будни (0)   |
| `sleep_hours`         | float | Продолжительность сна (часы) |
| `deep_sleep`          | float | Глубокий сон (часы)          |
| `rem_sleep`           | float | REM-сон (часы)               |
| `steps`               | int   | Количество шагов за день     |
| `active_minutes`      | int   | Минуты активности            |
| `resting_heart_rate`  | int   | Пульс покоя (уд/мин)         |
| `season`              | str   | Сезон (winter/spring)        |

# |         Функция             |                  Вопрос                                          |
1 | `weekday_vs_weekend_sleep()`| Насколько сон в выходные длиннее, чем в будни?                   |

3 | `most_active_day()`         | Какой день недели самый активный по шагам?                       |

# Примеры выводов (seed=42, 145 дней), ответ на вопрос "Какие выводы можно сделать на основе данных":

В выходные сон длиннее в среднем на ~0.9 часа по сравнению с буднями.
Обнаружена слабая положительная корреляция между шагами и сном (r ≈ 0.22).
Самый активный день — суббота (наибольшее среднее число шагов).
Зимой сон в среднем на ~0.75 часа длиннее, чем весной.
Глубокий сон отрицательно коррелирует с пульсом покоя (r ≈ -0.39): чем качественнее сон, тем ниже пульс.

## Технические детали
```bash
pandas и numpy
```

## Данные

Данные генерируются синтетически с помощью numpy, но выглядят относительно реалистично:

1. Средняя продолжительность сна взрослого: 7–8 часов 
2. «Социальный джетлаг»: +30–90 минут сна в выходные
3. Норма пульса покоя: 60–80 уд/мин
4. Среднее количество шагов: 6000–8000 в день 
5. Сезонные колебания сна: зимой сон длиннее на 30–60 минут

Для использования реальных данных с Fitbit/Garmin достаточно заменить fitness_data.csv на экспорт из приложения, сохранив названия колонок.
